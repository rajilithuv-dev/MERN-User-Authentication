MERN User Authentication

Project Overview

This project is a MERN Stack User Authentication application.

Technologies Used

- MongoDB
- Express.js
- React.js
- Node.js
- JavaScript
- CSS

Project Structure

- backend – Server-side application and registration API
- frontend – React user interface

Features

- User Registration
- Form Validation
- Backend API Integration
- MongoDB Database Connection

Installation

Backend

cd backend
npm install
npm start

Frontend

cd frontend
npm install
npm run dev

Environment Variables

Create a ".env" file inside the backend folder and configure your own database connection and secret values.
